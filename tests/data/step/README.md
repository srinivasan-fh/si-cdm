# Reference STEP files

Written by OpenCascade (used only to make these files, not by SI-CDM), AP214, to test
the STEP reader against an independent writer. `volumes.inc` lists each part's exact
volume. `assembly.step` holds a two-level assembly: two placements of *Bracket* (one
turned 90 degrees about Z) in *SubAssembly*, placed in *Top* with a *Pin*.
