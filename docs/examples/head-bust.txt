# A head-and-shoulders bust, sculpted the way a sculptor works in clay:
#   1. block out the big forms from stretched balls and fuse them (REMESH) with
#      large fillets, so they flow into each other;
#   2. add the eyeballs, the nose and the ears as smaller forms, fused tightly;
#   3. the neck and shoulders the same way, joined on;
#   4. the detail with brush strokes: lids, lips, brows, ears, neck muscles.
#   RUN docs/examples/head-bust.txt        (from the repository folder; about 25 s)
# Millimetres; z up, the face looks along -y. Strokes with SYMMETRY are mirrored
# across x = 0, so each feature is placed once, on the +x side. Each form is
# SPHERE 20 resting on a point, stretched by SCALE (and tilted by ROTATE) about it.

NEW
