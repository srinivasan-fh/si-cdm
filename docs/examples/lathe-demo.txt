# A shaft turned from bar: faced, rough and finish turned, the neck grooved, the bore
# drilled and bored, the front threaded M20 x 1.5, then parted off.  RUN docs/examples/lathe-demo.txt
CYLINDER 15 20 @0,0,0
CYLINDER 12 4 @0,0,20
CYLINDER 15 16 @0,0,24
CYLINDER 10 20 @0,0,40
BOOLEAN "Cylinder 1" UNION "Cylinder 2"
BOOLEAN "Cylinder 1" UNION "Cylinder 3"
BOOLEAN "Cylinder 1" UNION "Cylinder 4"
CYLINDER 4 16 @0,0,45
BOOLEAN "Cylinder 1" SUBTRACT "Cylinder 5"
LATHE SETUP "Cylinder 1" MATERIAL aluminium
LATHE TOOL 1 TURN NOSE 0.8 INSERT C
LATHE TOOL 2 TURN NOSE 0.4 INSERT D
LATHE TOOL 3 GROOVE 3
LATHE TOOL 4 DRILL 6
LATHE TOOL 5 BORE 5 NOSE 0.2
LATHE TOOL 6 THREAD
LATHE FACE
LATHE ROUGH TOOL 1 LEAVE 0.2
LATHE FINISH TOOL 2
LATHE GROOVE
LATHE DRILL
LATHE BORE LEAVE 0.1
LATHE FINISH INSIDE
LATHE THREAD PITCH 1.5 FROM 0 TO -14
LATHE PARTOFF
LATHE SIMULATE
