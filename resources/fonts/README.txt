UI fonts embedded into the app at build time (cmake/EmbedFonts.cmake).

Inter-Regular.ttf, Inter-SemiBold.ttf
  Inter 4.0 by The Inter Project Authors, SIL Open Font License 1.1 (OFL-Inter.txt).
  Converted from the OpenType (CFF) release to TrueType outlines, because Dear ImGui's
  rasteriser reads TrueType only, and subset to Latin plus the symbols the UI uses.

JetBrainsMono-Regular.ttf
  JetBrains Mono by The JetBrains Mono Project Authors, SIL Open Font License 1.1
  (OFL-JetBrainsMono.txt). Subset to Latin; used for the command line and numeric readouts.
